# Career and Competition in Industrial Era with GIS
**Studi kasus:** membandingkan sebaran peluang karier teknologi dan GIS di beberapa kota.

**Jalankan:** `python gis_career.py`, lalu buka `peta_peluang_karier.html` di browser. Peta dasar memerlukan internet.

Koordinat kota nyata, tetapi jumlah lowongan dan bidang kerja hanyalah data ilustratif, bukan statistik pasar kerja aktual.

## Instalasi

Gunakan Python 3.10 atau lebih baru. Dari folder repository, jalankan:

```bash
python -m venv .venv
```

Aktifkan lingkungan virtual:

- Windows: `.venv\Scripts\activate`
- Linux/macOS: `source .venv/bin/activate`

Pasang dependensi:

```bash
pip install -r requirements.txt
```

## Catatan

Lihat deskripsi studi kasus di atas sebelum menjalankan program. Jika `requirements.txt` kosong, program hanya memakai pustaka bawaan Python.
